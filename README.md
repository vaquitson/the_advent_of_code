# Advent of Code Solutions 🎄

This repository contains my solutions to **[Advent of Code](https://adventofcode.com/)** — a yearly programming challenge released every December, themed around Christmas.

## What is Advent of Code?
Advent of Code (AoC) is a series of daily coding puzzles (one per day from Dec 1 to Dec 25). Each day usually includes two parts, and the difficulty ramps up as the month progresses.

## Repository Structure
The exact structure may vary by year/language, but it typically follows a pattern like:

```
├── 2019/
│ ├── day_1/
│ ├── day_2/
│ └── ...
├── 2020/
│ ├── day_1/
│ └── ...
└── README.md
```

You can browse each year/day folder to find:
- The solution code
- (Optionally) input files and notes
- (Optionally) small helpers or scripts used for the puzzles

## Running the Solutions
Since languages/tools may differ per year, check the corresponding folder for instructions or build/run scripts.

Typical examples:
- Compile and run (C/C++): `make` or `cmake` + `./aoc_dayXX`
- Run scripts (Python/JS): `python dayXX.py` / `node dayXX.js`
- Rust: `cargo run`

If a folder includes a `Makefile`, `Cargo.toml`, or similar, use that as the source of truth.

## Notes
- Inputs are usually personal to each AoC account. If input files are not included, you can download yours from the AoC website once logged in.
- Some solutions prioritize clarity; others prioritize speed or experimentation depending on the puzzle.
